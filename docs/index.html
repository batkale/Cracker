Cracker

A personal tracker for internship and placement applications.

Cracker keeps one list of every application — company, role, stage, deadline — instead of scattering them across notes and inboxes. It runs entirely on the machine of the person using it.

What it does

  • Tracks applications through a pipeline: Wishlist, Applied, OA/Assessment, Interview, Offer, Rejected/Withdrawn.
  • Reads the user's own Gmail, read-only, to spot status updates — an assessment invitation, a rejection — and suggests the matching change.
  • Flags deadlines that are close, and assessments that have gone quiet.
  • Shows the pipeline as a table, a board, and a few summary charts.

Where the data lives

On the user's own computer, and nowhere else. There is no server, no account and no third party. The Gmail connection is read-only and is used solely to update that local list.

Scope of Gmail access

Cracker requests one scope, https://www.googleapis.com/auth/gmail.readonly. That permits reading mail. It does not permit sending, deleting, or modifying anything in the mailbox.
