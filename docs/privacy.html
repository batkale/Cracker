Privacy policy

Cracker — last updated 19 October 2026

Cracker is a personal application tracker that runs on the computer of the person using it. It has no server, no user accounts, and no operator other than that person.

What is accessed

With the user's explicit consent, Cracker reads their own Gmail mailbox using a single Google OAuth scope:

https://www.googleapis.com/auth/gmail.readonly

This grants read access only. Cracker cannot send, delete, label or otherwise modify any message, and it does not request permission to do so.

What is read, and why

Cracker searches recent mail for messages that look like responses to job applications. For those messages only, it keeps the sender, date, subject and an extract of the body, so it can work out which application a message concerns and what stage it has reached. Mail that does not match is not retained.

Where it is stored

  • In files inside the application's own folder on the user's computer.
  • In that computer's web browser local storage, for the tracker page.

Nothing is uploaded anywhere. There is no database, no cloud storage, no analytics, no telemetry and no logging to any external service.

What is shared

Nothing. No data is transmitted to the developer or to any third party. The only network connection Cracker makes is directly to Google's Gmail API, to read the user's own mail on their behalf.

Retention and deletion

Data stays until the user deletes it. Removing the application's folder removes everything it holds. Access can be withdrawn at any time from Google Account permissions, which immediately stops any further reading of mail.

Children

Cracker is not directed at children and is not intended for use by them.
